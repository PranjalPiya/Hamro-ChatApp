# 🗨️ Flutter ChatApp

A simple, clean real-time chat application built using **Flutter**, powered by **Firebase Authentication** and **Cloud Firestore** for chat data.


---

## 🚀 Features

- 🔐 Firebase Authentication (Email/Password)
- 💬 Real-time messaging with Firestore
- 📱 Responsive & clean Flutter UI
- 🧾 Message timestamps
- 👤 User login, registration & logout
- 🔄 Auto-scroll to latest messages

---

## 🛠️ Tech Stack

- **Flutter** (UI Toolkit)
- **Dart** (Programming Language)
- **Firebase Authentication** (User Login/Signup)
- **Cloud Firestore** (Real-time DB for messages)
